依据《开发设计文档.md》v1.0 与《需求文档-详细版.md》功能说明绘制 · 平台：微信小程序（uni-app + vant-weapp 风格）· 设计尺寸 375 × 812
覆盖 v1.0 全部核心页面（Onboarding / 首页 / 替换 / 记录 / 食物库），含 v1.1（统计、自定义食物）与 v1.2（AI 建议）预埋位。
示例用户：男 · 28岁 · 178cm · 75kg BMR 1718 × 肌肉修正 1.04 × 活动系数 1.55 = TDEE 2770 目标：减脂 −400 → 每日目标 2370 kcal 餐次分配：早 25% · 午 35% · 晚 30% · 加餐 10%
碳水 蛋白质 脂肪 主色 / 达成（WeChat Green #07C160）
